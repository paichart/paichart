IGP-T1 Triangle Run Sheet

The as-run record of a complete routing-protocol migration — three live switches, five gated applies, one honest refusal, and the round that answered it. 2026-08-30/31.

What this actually is

One sentence of intent — migrate this three-switch network from OSPF to IS-IS without dropping traffic — became a finished migration: planned by AI legs, checked by machine and by independent AI reviewers, applied by a human-delegated operator, on live devices, with every step's evidence preserved. This sheet is not a plan; it is the record of what happened, including the one thing that was refused and why the refusal was the system's best moment.

The one thing to hold onto: no agent touches a device. A leg produces a change package — the exact commands, the expected outputs, and a rollback. The operator reads it, verifies it, and pastes it. When this sheet says “applied,” a delegated operator did that, with the package's own validation steps as the acceptance test — and in one case, refused to.

The refusal is the feature

Everything in P4's package worked except one property: the rollback's provenance. The commands would likely have executed; the math was fine. But a rollback for the leg that deletes the old protocol must be the old protocol's config exactly as harvested — a paraphrase is a guess wearing a quote's clothing, and the moment you need a rollback is exactly the moment you cannot afford a guess. The reviewer did not suspect this; it proved it, from an anachronism the author left behind. The system then did the only correct thing: stopped, said precisely why, and left the network in a stable, reversible state until a package existed that could pass a character-for-character test. The next day, one did.

What this buys a change-approval board: the refusal, the evidence, the parked-safe intermediate state, and the completion are all persisted records — not this document's claims. Ask for them.

Honest notes

The devices are lab containers, not production hardware; the operator applies were performed by a delegated AI over ssh — occupying the same out-of-band, human-gated lane a human engineer would, with the human owner delegating explicitly and every action evidenced. Two package defects were found by the operator during applies and are recorded as round findings (an unsatisfiable byte-diff clause in P1; the P4 rollback above): the tiers are good, and the gate is still an evidence step, not a rubber stamp. The rollback-verbatim property, having now failed once as prose, is queued to become a machine check — that pipeline (slip → catch → rule → code) is how every guard in this engine was born.
