# Leg Replay Lab — Experiment Ledger

> **Created**: 2026-10-08 (Steve approved) · **Owner**: `model-evaluation-specialist` · **Append-only**
>
> One row per PAID run of the leg replay lab (`npm run lab:leg-replay`), plus $0 runs only when they decided
> something. One place for what was tested, the rule, the real cost, the verdict, and which arms are reusable as
> baselines. The run folders (`scripts/leg-replay-lab/runs/`) are gitignored and local-only; they disappear, this
> file does not.
>
> **Not a task list.** Open work lives in `cline_docs/follow-ups/OPEN-REGISTER-2026-09-23.md` ("filed" means
> written there). Each row links to its register entry.

## Rules

1. **Add the row in the SAME commit as the results write-up** (Protocol 16 non-negotiable 9).
2. **Never edit a past row.** Append a correction below the table, marked `CORRECTION <date> to row <id>`.
3. **A reused baseline cites the row it reuses** and how the reuse was proven (`cmp` of the saved
   `<node>/<arm>/*.system.md` / `*.user.md`, or the `reviewerPromptSha` / `authorPromptSha` in `manifest.json`).
4. **Cost estimates for a new run come from this ledger's actual $/sample** for that model + role (table below),
   not from the lab's estimator, which does not model a longer model's output (Opus ran ~60% over it).
5. Knowledge, may be quoted: node ids, costs, counts, verdicts and commit hashes only. No rig values, customer
   data or execution ids.

How the cost columns were computed (backfill, 2026-10-08): sum of `sample.json` `costUsd` per run folder; per role
and model, the sum of `calls[].costUsd` divided by the samples that role ran in. Per-sample cost includes prompt-cache
hits from earlier runs, so a re-run of the same prompts can read cheaper.
