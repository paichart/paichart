# Academic project briefs

Project proposals offered to universities and their students — written to be handed to a supervisor
as-is.

These are **genuine gaps**: things that do not exist publicly and that we think are worth building.
None of them sit on pAIchart's delivery path, so no student is working against our deadlines.

## Terms

- **No IP assignment, no exclusivity, no deliverable owed to us.** Publish it, keep the copyright,
  license it however your institution prefers.
- **Support is real, not nominal** — a working lab that runs on a laptop, a platform account, the
  integration specification, and technical review at each milestone from the engineers who built the
  platform side.
- Where a brief overlaps something we are also building, it says so plainly.

## Open proposals

Both describe the **same build** — an MCP server that lets an AI system read live network devices —
framed for different students. Pick by the student, not by the topic.

| Proposal | For | Judged on |
|---|---|---|
| **[Connecting AI Systems to the Real World, Safely](THESIS-PROPOSAL-ai-student.md)** | AI / ML / NLP | A measured experiment in model behaviour — prompt injection, LLM-as-reviewer, or tool-interface design |
| [An MCP Server for Network Devices](network-device-mcp-server-thesis-brief.md) | Network / systems / security engineering | Gap analysis and design against a real integration contract |

**Start with the proposal itself** — each is self-contained and assumes no knowledge of our platform.
[`CONCEPTS.md`](CONCEPTS.md) is optional background for readers who want more on MCP and the hub.
